Computational Intelligence

Designed, trained, and evaluated machine learning models for binary classification on an imbalanced real-world dataset — using techniques applicable to game AI, player behaviour modelling, and adaptive difficulty systems.

Overview

This project involved building ML models to classify productivity outcomes as satisfactory or unsatisfactory. The key challenge was handling an imbalanced dataset and identifying which features most influenced the outcome — requiring careful preprocessing, model selection, and iterative evaluation.

Methodology

01

Data Preprocessing & Feature Engineering

Handled missing values, normalised numerical features, and encoded categorical variables. Created new engineered features to better capture patterns in workplace metrics such as efficiency, overtime, and department type.

02

Neural Network — Keras

Built an initial neural network with a single hidden layer using ReLU activation and dropout regularisation. Tuned hyperparameters including learning rate and dropout rate through iterative experimentation.

03

Random Forest — Scikit-learn

Benchmarked against a Random Forest classifier, which outperformed the neural network on the imbalanced dataset due to its ensemble approach and stronger generalisation on unseen data.

04

Evaluation & Visualisation

Compared models across accuracy, precision, recall, and F1-score. Produced clear visualisations of both feature distributions and model performance to communicate findings to a non-technical audience.

Key Takeaways

  • End-to-end experience with a real-world ML pipeline: preprocessing, feature engineering, training, evaluation, and communication of results
  • Practical understanding of how to handle imbalanced datasets and select models accordingly
  • Hyperparameter tuning through iterative experimentation on neural network architecture and dropout configuration
  • Skills in communicating technical model results visually to non-technical stakeholders
  • These techniques are directly applicable to game AI development, player behaviour segmentation, and adaptive difficulty balancing
