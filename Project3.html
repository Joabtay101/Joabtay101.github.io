Virtual Worlds Using the GPU

A real-time 3D environment built from scratch in C++ and OpenGL, with custom GLSL shaders driving animated textures, UV manipulation, and performance-optimised rendering workflows.

Overview

This project focused on using GPU programming techniques to build a visually dynamic and efficient 3D environment. The core challenge was implementing animated textures and optimising rendering workflows using custom shaders and texture atlas manipulation — producing a scalable system suitable for games, simulations, or interactive environments.

Technologies Used

Language C++
Graphics API OpenGL
Libraries GLAD, GLFW, GLM, stb_image
Environment Visual Studio

Implementation Details

  • Used stb_image for texture loading and binding into OpenGL texture units
  • Wrote custom GLSL fragment and vertex shaders to manipulate UV coordinates for smooth frame-by-frame animation
  • Built a real-time timing system to synchronise animation frames with the rendering loop at consistent rates
  • Minimised draw calls and texture switches to reduce GPU overhead and improve rendering efficiency
  • Implemented multiple animation types including frame cycling and scrolling background effects

Challenges Faced

  • Precisely calculating UV offsets within texture atlases to prevent texture bleeding between animation frames
  • Debugging shader behaviour and verifying frame transitions directly in OpenGL without engine abstractions
  • Managing GPU memory efficiently to keep the system scalable as asset counts increased

Results & Takeaways

Successfully built an animated texture system from scratch suitable for real-time 3D environments. The project gave me hands-on experience with GPU pipelines, shader debugging, and performance profiling in OpenGL — skills that transfer directly to any role involving real-time graphics, game engines, or performance-sensitive rendering systems.
